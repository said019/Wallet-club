# AgendaFull Studio Design

Date: 2026-05-13

## Goal

Reposition AgendaFull from a loyalty-card landing page into a premium digital systems studio for fitness and wellness businesses. The site should sell AgendaFull as a team that designs and builds custom systems for studios that want a better student experience and a cleaner operation.

## Core Positioning

AgendaFull creates custom digital systems for studios that want to feel as premium online as they do in class.

The main promise is student experience first, operational clarity second:

- Students can reserve, pay, check in, manage memberships, receive reminders, and use Apple Wallet without friction.
- Studio owners get a system shaped around their real workflow instead of forcing their business into disconnected tools.
- The work is custom, consultative, and practical, not a generic app template.

## Brand Role

AgendaFull should present itself as a studio or team, not as one person and not as a single software product. The voice uses "we" and speaks with confidence, clarity, and warmth.

The brand should feel:

- Premium, but not cold.
- Technical, but not filled with jargon.
- Local-business aware, but not cheap or casual.
- Calm, organized, and capable.

Avoid framing AgendaFull as only "tarjetas de lealtad", only "agenda de citas", or only "software para reservas". These are modules inside a broader service.

## Primary Audience

The first audience is fitness and wellness studios:

- Pilates studios
- Barre, yoga, cycling, dance, or boutique training studios
- Wellness spaces with classes, packages, memberships, and recurring students

Secondary audiences can appear later as proof of adaptability:

- Barber shops and beauty spaces
- Restaurants and food businesses
- Clinics or service businesses with reservations

## Hero Direction

Headline:

> Sistemas digitales para studios que quieren sentirse tan premium como sus clases.

Supporting copy:

> Creamos reservas, membresías, Apple Wallet, pagos y automatizaciones a la medida de tu studio, para que tus alumnos vivan una experiencia fluida desde que apartan hasta que vuelven.

Primary CTA:

> Diseñar mi sistema

Secondary CTA:

> Ver lo que podemos construir

Hero visual should show multiple product surfaces, not just one wallet card:

- A student booking view
- A membership or package card in Apple Wallet
- A studio admin schedule
- A WhatsApp reminder or check-in confirmation

## Page Structure

1. Navigation
   - Logo: AgendaFull
   - Links: Experiencia, Sistemas, Casos, Proceso
   - CTA: Hablar por WhatsApp

2. Hero
   - Premium studio systems message
   - Multi-surface interface visual
   - Small proof line: "Reservas, membresías, Wallet, pagos y automatización para studios."

3. Problem Section
   - Studios often patch together Instagram DMs, WhatsApp, spreadsheets, payment links, manual reminders, and disconnected booking tools.
   - The pain is not only admin work. It is that the student experience stops feeling premium.

4. Experience Section
   - Explain the student journey:
     - Finds the class
     - Reserves in seconds
     - Pays or uses membership
     - Receives reminders
     - Checks in
     - Returns with less friction

5. Systems Section
   - Modules AgendaFull can build:
     - Reservations and class schedules
     - Memberships and class packs
     - Apple Wallet and Google Wallet passes
     - Payments and order flows
     - WhatsApp reminders
     - Admin dashboards
     - Loyalty and retention flows
     - Custom workflows by studio type

6. Fitness Case Study Section
   - Use fitness as the main case:
     - "Para un studio de pilates"
     - Show a system stack: booking, packages, Wallet pass, reminders, admin.
   - Avoid inventing numeric results unless real numbers are provided.

7. Other Business Types
   - Show adaptability without diluting the page:
     - Barberías: reservas and client history
     - Comida: orders and customer loyalty
     - Servicios: appointments and reminders

8. Process Section
   - Four steps:
     - Understand your operation
     - Design the digital flow
     - Build and connect the system
     - Launch, measure, and improve

9. Final CTA
   - "Construyamos el sistema que tu studio necesita."
   - WhatsApp CTA with a prefilled message.

## Visual Direction

Move away from the current cream and green loyalty-card look. The new style should feel more like a premium digital studio for boutique fitness brands.

Color strategy:

- Warm off-white base for calm and readability.
- Deep ink or charcoal for confidence.
- Muted plum, oxblood, or clay as the main accent.
- Soft mint or electric lime only as a small digital signal, not the dominant brand color.

Potential palette:

- Base: `oklch(96% 0.012 80)`
- Ink: `oklch(18% 0.018 265)`
- Muted plum: `oklch(38% 0.075 335)`
- Clay: `oklch(62% 0.09 38)`
- Soft mint: `oklch(82% 0.08 165)`
- Line: `oklch(84% 0.018 80)`

The design should use restrained color with high-quality contrast. Avoid a generic teal SaaS look.

## Typography

Use a type system that feels editorial and digital:

- A confident sans serif for headings.
- Comfortable body text with generous line height.
- Hero type should be large but not shouty.
- Avoid tiny gray text and repeated centered card grids.

The current `DM Sans` can stay if implementation speed matters, but the design should use stronger hierarchy and more varied rhythm.

## Interaction And Motion

Motion should be subtle:

- Interface panels can drift or reveal on scroll.
- Buttons should have precise hover states.
- No bouncy effects.
- No decorative glassmorphism.

## Legal Pages

Privacy and terms pages should be updated from "tarjetas de lealtad digitales" to "sistemas digitales, reservas, membresías, pagos, comunicación y automatización". Legal copy can stay simple, but it should no longer describe AgendaFull as only a loyalty service.

## Implementation Notes

The current project is a static HTML site:

- `index.html`
- `privacy.html`
- `terms.html`
- local image assets

The first implementation pass can remain static HTML/CSS. No build tool is required unless later requested.

## Success Criteria

- A visitor understands in the first viewport that AgendaFull builds custom digital systems for fitness studios.
- The site no longer feels like a wallet loyalty-card product.
- The copy explains the value in business terms, not technical jargon.
- The visual style feels premium, modern, and distinct from the current green/cream design.
- The page still makes it easy to contact AgendaFull through WhatsApp.
